# Frontend source

The 2024 theme was imported from [vastsa/FileCodeBoxFronted](https://github.com/vastsa/FileCodeBoxFronted)
at commit `2d6173e0d4fe4d543479143842408abb50bd5f9b`.
The public transfer pages are maintained here together with the backend. The
original admin pages, storage clients, localization, and preview utilities are
retained. Original authors: Lan and FileCodeBoxFronted contributors. See the
repository's LICENSE for FileCodeBox licensing information.

The npm lockfile's download URLs use the public npm registry instead of the
upstream development registry mirror; package versions and integrity hashes
are preserved.
